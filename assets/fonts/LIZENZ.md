# Schriften

Alle Schriften stammen von Google Fonts und stehen unter freien Lizenzen. Die
meisten unter der SIL Open Font License 1.1, Special Elite und Permanent Marker
unter der Apache License 2.0. Beide erlauben den Einsatz auf Websites und das
Einbetten der Dateien.

Neu laden: `npm run fonts` im Hauptordner. Das Skript `tools/fonts.mjs` holt die
lateinischen Teilmengen und schreibt `fonts.css` neu.
